# 📄 Hoja de Vida en HTML y CSS

## 📌 Descripción

Este proyecto consiste en el desarrollo de una **Hoja de Vida** utilizando **HTML5** y **CSS3**. Fue realizado como actividad académica para poner en práctica la creación de estructuras semánticas, la aplicación de estilos y la organización de contenido siguiendo el diseño propuesto.

---

## 🎯 Objetivos

- ✅ Construir una página web utilizando HTML5.
- ✅ Aplicar estilos con CSS3.
- ✅ Organizar la información mediante etiquetas semánticas.
- ✅ Utilizar Flexbox y CSS Grid para la distribución del contenido.
- ✅ Desarrollar una interfaz clara, ordenada y agradable visualmente.

---

## 🛠️ Tecnologías utilizadas

- 🌐 HTML5
- 🎨 CSS3
- 📐 CSS Grid
- 📦 Flexbox
- 🔤 Google Fonts (Poppins)

## 📝 Contenido de la hoja de vida

La página está organizada en las siguientes secciones:

- 👤 Información personal
- 📖 Perfil profesional
- 🎓 Estudios básicos
- 💼 Estudios profesionales
- 🌎 Idiomas
- 💡 Habilidades (Skills)

---

## ▶️ ¿Cómo ejecutar el proyecto?

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en **Visual Studio Code**.
3. Ejecutar el archivo **`index.html`** en un navegador web o utilizar la extensión **Live Server**.
